<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Live SQLite → snapshot/restore path | Concurrent durable truth crosses filesystem boundaries. |
| Scope → export file | Personal stored records are copied into a portable artifact. |
| Human/API intent → destructive lifecycle action | Ambiguous/replayed/tampered intent could cause irreversible loss. |
| Generated artifacts → Git | Personal/runtime data must remain outside commits. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-03-05-01 | Tampering / Denial of Service | snapshot/restore | mitigate | SQLite online backup, finite bounds, hashes/manifests, exact checks, isolated new targets, corruption/fault tests. |
| T-03-05-02 | Information Disclosure | export/path | mitigate | Scope transaction, field allowlist, containment/no-follow, mode 0600, atomic publish. |
| T-03-05-03 | Tampering / Denial of Service | deletion | mitigate | Exact action inventory, expiring digest-bound one-use confirmation, transaction, per-target verification/residuals. |
| T-03-05-04 | Repudiation | lifecycle outcome | mitigate | Fixed complete/incomplete/blocked outcomes with counts/hashes/reason codes and no vacuous check set. |
| T-03-05-05 | Information Disclosure | local disk | accept | No at-rest encryption claim; contained mode-restricted files and explicit limitation. |
| T-03-05-SC | Tampering | package supply chain | mitigate | Standard library plus existing locked stack; no install, sync, manifest, or lock mutation. |
</threat_model>
