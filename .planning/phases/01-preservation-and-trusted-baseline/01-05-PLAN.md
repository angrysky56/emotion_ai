<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser origin → localhost FastAPI | An unrelated website can attempt cross-origin local requests. |
| Test process → production app import | Import/lifespan may start stateful services or touch real data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-LH | Spoofing / Tampering | CORS and request parsing | mitigate | Loopback default, explicit origins, credentials off, strict JSON Content-Type; no authentication added per D-01. |
| T-01-SM | Tampering | characterization harness | mitigate | Temporary cwd, suppressed lifespan, fakes, hard timeout, unchanged-root assertions. |
| T-01-CL | Information Disclosure | child output | mitigate | Synthetic payloads and normalized JSON only; no production content/log capture in committed artifacts. |
| T-01-FT | Repudiation | child status | mitigate | Timeout/crash/malformed output are explicit non-pass results. |
| T-01-SC | Tampering | package supply chain | mitigate | Use installed FastAPI/HTTPX/pytest only; no dependency changes. |
</threat_model>
