## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Caller identifier/format → local filesystem | Untrusted URL/query values influence profile and export paths. |
| Configured storage base → resolved path | A local symlink can redirect otherwise safe components. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-PE | Tampering / Information Disclosure | profile/export path construction | mitigate | Positive component/format validation plus final resolved-root containment. |
| T-01-LH | Spoofing / Tampering | export endpoint | mitigate | Preserve the Plan 01-05 origin/JSON boundary; add no authentication per D-01. |
| T-01-FT | Repudiation | export success response | mitigate | Return success only after a file exists and parses; do not claim data completeness. |
| T-01-SM | Tampering | existing local data | mitigate | Temp-only tests and no migration/deletion/storage-format changes. |
| T-01-SC | Tampering | package supply chain | mitigate | Stdlib pathlib plus installed framework only; no install or lock change. |
</threat_model>
