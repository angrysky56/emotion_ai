<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub workflow to third-party actions | External action code runs with repository/runner permissions. |
| Self-hosted runner to local Ollama | A network-shaped service crosses into a host with local models/resources. |
| Provider output/errors to CI logs | Untrusted content can leak prompts, responses, credentials, endpoints, or host details. |
| Job result to release confidence | Skip, block, timeout, or swallowed failure can be mislabeled as proof. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-18-01 | Tampering | GitHub Actions dependencies | mitigate | Use reviewed immutable full commit SHAs and static contract tests. |
| T-02-18-02 | Information Disclosure | live/provider logs and artifacts | mitigate | Synthetic input plus safe metadata-only error/report serialization and no raw content. |
| T-02-18-03 | Denial of Service | Ornith live call | mitigate | Explicit opt-in, non-mutating preflight, whole-operation timeout, local cancellation cleanup. |
| T-02-18-04 | Repudiation | CI success labels | mitigate | Independent jobs, adversarial false-success tests, uploaded blocked classification, no swallowed exits. |
| T-02-18-05 | Spoofing | local Ollama service/model | mitigate | Loopback/configured endpoint and explicit model-list confirmation before live execution. |
| T-02-18-SC | Tampering | npm/pip/cargo installs | mitigate | Prior human legitimacy approval, repository locks, npm ci/locked uv, and pinned action dependencies. |
</threat_model>
