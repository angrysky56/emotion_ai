<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Aura → Ollama/OpenRouter HTTP | Requests cross a local or remote service boundary with explicit timeout/cancellation limits. |
| Provider stream/tool chunks → Aura | Untrusted chunks may be partial, malformed, costly, or content-bearing. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-02-PS | Tampering / Repudiation | compatible stream terminal | mitigate | Validate chunks/order; no `Completed` after any error, timeout, resource bound, or cancellation. |
| T-02-CD | Denial of Service | timeout/retry/tool loops | mitigate | Explicit HTTP timeouts, zero SDK retries, one runtime deadline, bounded tool turns. |
| T-02-PL | Information Disclosure | exceptions/headers/content | mitigate | Typed safe mapping and sentinel redaction tests; no raw response/traceback logs. |
| T-02-SC | Tampering | package supply chain | mitigate | Reuse locked OpenAI/HTTPX packages; no new install. |
</threat_model>
