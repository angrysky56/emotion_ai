<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Model-produced tool call → Aura executor | Names and JSON arguments are untrusted and may collide or be malformed. |
| MCP/internal tool result → model/provider | Results may contain sensitive content, huge payloads, or exceptions. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-02-TV | Tampering / Elevation | tool name/schema/arguments | mitigate | Collision rejection, immutable registry, JSON-schema validation, bounded dispatch. |
| T-02-PL | Information Disclosure | tool results/diagnostics | mitigate | Bounded safe result metadata; no arguments/results/raw exception in public/default logs. |
| T-02-CD | Denial of Service | tool execution | mitigate | Finite timeout/output/tool-turn bounds and typed resource failures. |
| T-02-SC | Tampering | package supply chain | mitigate | No install or manifest change. |
</threat_model>
