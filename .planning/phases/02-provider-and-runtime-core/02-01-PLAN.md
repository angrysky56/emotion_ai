## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-02-PV | Tampering / Repudiation | result and stream terminal types | mitigate | Only `ProviderResult`/`Completed` license success; explicit typed failures cover every non-success state. |
| T-02-PL | Information Disclosure | failure/public serialization | mitigate | Construct output from a safe-field allowlist and test secret/content sentinels adversarially. |
| T-02-PC | Spoofing / Cost | provider selection | mitigate | Unknown values fail; cloud is explicit and selected credentials are validated before construction. |
| T-02-SC | Tampering | package supply chain | mitigate | No dependency changes in this plan; use the locked environment only. |
</threat_model>
